# shubhamdwivedi.com

Personal site of **Shubham Dwivedi, PMP®** — Technical Program Manager (Gen AI · Conversational AI · ServiceNow) and bansuri flautist.

Static site served by GitHub Pages from `main` (custom domain in `CNAME`). No build step.

```
index.html            page content
assets/css/style.css  styles (warm-dark theme, responsive)
assets/js/main.js     nav, reveal animations, accordion, filters
assets/img/           logo.svg + responsive WebP photos (name-<width>.webp, served via srcset)
assets/media/         performance videos (H.264, faststart)
```

Preview locally: `python3 -m http.server` then open http://localhost:8000.
